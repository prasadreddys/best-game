NEON RUSH — a 3D hover-racer in Three.js: race 3 laps around a neon loop at dusk, thread 6 glowing gates per lap (miss one and it costs 3 seconds), ride 4 boost pads, and beat your best time. W/S drive, A/D steer, Shift boosts, R restarts, P pauses, M mutes. Synthesised WebAudio engine hum, gate chimes and boost whooshes — no audio files, no network requests, no build step. Three.js 0.187.0 vendored under game/vendor/three/.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
